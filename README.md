# Smart Teacher

A .NET solution containing an ASP.NET Core API and an MVC web client.

## Projects

- `Smart_teatcher/` — API project
- `Smart_teatcher_MVC/` — MVC web client
- `Smart_teatcher.sln` — Visual Studio solution

## Tech stack

- .NET 8
- ASP.NET Core Web API
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Swagger / OpenAPI

## Run locally

Open `Smart_teatcher.sln` in Visual Studio, restore dependencies, configure each project's `appsettings.json`, and run the API and MVC projects. Each can also be started with `dotnet run --project <project-file>`.
